# 10 · 输入系统（键盘 / 鼠标 / 滚轮 / 光标）

PureEcs 内置了一套 Bevy 风格输入插件，基于浏览器 DOM 事件驱动，把原始事件整理成**每帧可轮询的三态资源**：

- `pressed`（按住中）
- `justPressed`（本帧刚按下）
- `justReleased`（本帧刚松开）

## 快速开始

```ts
import { App, InputPlugin } from 'pureecs';

const app = new App()
  .addPlugin(new InputPlugin())       // 注册输入资源 + DOM 监听
  .addSystem(Stages.PreUpdate, readInput)
  .run(1);
```

启用后，`InputPlugin` 自动在**首次 update** 时把监听器挂到 `document`，并插入以下资源：

| 资源 | 内容 |
| --- | --- |
| `KeyboardInput` | 键盘三态（`KeyCode`） |
| `MouseInput` | 鼠标按钮三态（`MouseButton`） |
| `MouseWheel` | 本帧滚轮累计 delta（tick 末清零） |
| `MousePosition` | 光标当前位置（屏幕坐标） |

插件还在 `Stages.Last` 注册了一个清理系统：每帧末自动清空 `justPressed/justReleased` 与滚轮累计。**因此系统必须在本 tick 内消费这些瞬时状态**。

## 三态语义（最重要的心智模型）

| 方法 | 何时为 true | 典型用途 |
| --- | --- | --- |
| `pressed(key)` | 只要按住（跨帧持续） | 角色持续移动 |
| `justPressed(key)` | 仅按下那一个 tick | 跳跃、开枪（单击事件） |
| `justReleased(key)` | 仅松开那一个 tick | 松开蓄力、扳机释放 |

```ts
import { App, InputPlugin, params, Res, Query, KeyCode, MouseButton } from 'pureecs';

const input = params(
  Res(KeyboardInput),
  Res(MouseInput),
).system((keyboard, mouse) => {
  if (keyboard.justPressed(KeyCode.Space)) jump();       // 单击
  if (keyboard.pressed(KeyCode.KeyD)) moveRight();       // 按住持续
  if (mouse.justPressed(MouseButton.Left)) fire();       // 单击
});
```

> 用 `KeyboardEvent.code` 布局无关命名：`KeyW`/`ArrowUp`/`Digit1`/`Space`/`ControlLeft`…（`KeyCode` 是完整 `code` 字符串的字面量联合，自带补全）。

## 按键辅助 API

```ts
keyboard.anyPressed([KeyCode.KeyW, KeyCode.ArrowUp]);      // 任一按住
keyboard.anyJustPressed([KeyCode.KeyA, KeyCode.ArrowLeft]); // 任一刚按下
keyboard.pressedSet();   // ReadonlySet<KeyCode>，遍历所有按住键
```

`Input<T>` 是通用三态跟踪器，`KeyboardInput extends Input<KeyCode>`、`MouseInput extends Input<MouseButton>`。想跟踪自定义"键"（如手柄按键）可自己 `insertResource(new Input<MyButton>())`，手动 `press/release/clear`。

## 鼠标：按钮 / 位置 / 滚轮

```ts
import { params, Res, MousePosition, MouseWheel, MouseButton } from 'pureecs';

const mouse = params(
  Res(MousePosition),
  Res(MouseWheel),
  Res(MouseInput),
).system((cursor, wheel, buttons) => {
  // 光标屏幕坐标（clientX/clientY）
  console.log(cursor.x, cursor.y, cursor.inBounds);

  // 滚轮：x>0 右滚 / y>0 下滚；每帧末清零
  camera.zoom += wheel.y * 0.01;

  // 按钮三态
  if (buttons.justPressed(MouseButton.Right)) contextMenu();
  if (buttons.pressed(MouseButton.Left)) drag();
});
```

要点：

- `MousePosition.inBounds`：光标是否位于监听目标内（移出时置 false）；
- `MouseButton`：`'Left' | 'Right' | 'Middle' | 'Back' | 'Forward'`；
- 滚轮 `deltaMode`（行/页）已由 `MouseWheel.feed` 归一化；
- `justPressed/justReleased/滚轮` 都是**帧级瞬时量**，本 tick 内消费。

## 把输入限制到指定元素：InputTarget

默认监听 `document`。游戏通常只希望捕获某块 canvas 上的输入（例如不让页面滚动），此时插入 `InputTarget`：

```ts
import { App, InputPlugin, InputTarget } from 'pureecs';

const canvas = document.getElementById('game') as HTMLCanvasElement;

new App()
  .addPlugin(new InputPlugin())
  .insertResource(new InputTarget(canvas, true))   // 第二个参数：是否 preventDefault
  .run(1);
```

- 监听器在**首次 update 时**读取 `InputTarget` 决定挂载对象与 `preventDefault`；
- `preventDefault=true` 会阻止浏览器默认行为（如滚轮翻页、右键菜单），并以非 passive 方式监听；
- **必须在第一次 update 之前** `insertResource(new InputTarget(...))`，否则插件默认挂了 `document`。

## 修饰键（Ctrl/Shift/Alt/Meta）

浏览器里修饰键不会自己触发 keydown/keyup，因此插件做了补充处理：无论按下的是哪个键，只要事件带 `shiftKey/ctrlKey/altKey/metaKey`，就会把对应的 `ShiftLeft/ControlLeft/AltLeft/MetaLeft` 视为按住（抬起时同步释放）。

```ts
// Ctrl+单击 = 特殊操作
if (keyboard.pressed(KeyCode.ControlLeft) && mouse.justPressed(MouseButton.Left)) {
  specialAction();
}
```

## 播放器控制完整示例

```ts
import { App, World, InputPlugin, DefaultPlugin, params, Query, Res, Time, KeyCode, MouseButton } from 'pureecs';

class Position { constructor(public x = 0, public y = 0) {} }
class Velocity { constructor(public x = 0, public y = 0) {} }
class Player {}
class PlayerFired {}

// 启动系统：生成一个玩家
function setup(world: World) {
  world.spawnWith(new Position(100, 100), new Velocity(0, 0), new Player());
}

// 输入系统：把按键映射到速度（PreUpdate，先于移动）
const steer = params(Query(Velocity, With(Player)), Res(KeyboardInput)).system((rows, kb) => {
  for (const [vel] of rows) {
    vel.x = 0;
    vel.y = 0;
    if (kb.pressed(KeyCode.KeyA) || kb.pressed(KeyCode.ArrowLeft))  vel.x -= 1;
    if (kb.pressed(KeyCode.KeyD) || kb.pressed(KeyCode.ArrowRight)) vel.x += 1;
    if (kb.pressed(KeyCode.KeyW) || kb.pressed(KeyCode.ArrowUp))    vel.y -= 1;
    if (kb.pressed(KeyCode.KeyS) || kb.pressed(KeyCode.ArrowDown))  vel.y += 1;
  }
});

// 帧率无关移动（Update）
const move = params(Query(Position, Velocity), Res(Time)).system((rows, time) => {
  for (const [pos, vel] of rows) {
    pos.x += vel.x * 200 * time.delta;
    pos.y += vel.y * 200 * time.delta;
  }
});

// 开火：Space 单击（可改写为事件发布，见 docs/06）
const shoot = params(Query(Player), Res(KeyboardInput)).system((_, kb) => {
  if (kb.justPressed(KeyCode.Space)) {
    console.log('fire!');
  }
});

const app = new App()
  .addPlugin(new DefaultPlugin())     // Time 资源
  .addPlugin(new InputPlugin())       // 输入资源 + DOM 监听
  .addStartupSystem(setup)
  .addSystem(Stages.PreUpdate, steer)
  .addSystem(Stages.Update, move)
  .addSystem(Stages.Update, shoot);

// 浏览器环境里配合 rAF 驱动：
function frame() {
  app.update();
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);

// 页面卸载/切场景时释放 DOM 监听：
// app.destroy();
```

## destroy：释放 DOM 监听

`InputPlugin.destroy()` 会移除它挂载的所有事件监听器，避免泄漏。当你不再需要输入时：

```ts
app.destroy();          // 触发所有插件的 destroy（逆序）
// app.update();        // 之后调用会抛 'App has been destroyed'
```

## 与"自定义输入"整合的建议

- **原始输入 → 意图**：在 `PreUpdate` 读取三态资源，向实体速度/事件（如 `PlayerJumped`）转换；
- **不要在 `justPressed` 分支里依赖多个 tick 的累积**：瞬时量每帧清理；
- **跨帧需要"记住"某次按下**：用一个布尔资源/`Local`/事件发布，而不是期待 `justPressed` 保持。

## 小结

- `InputPlugin` = 注册资源 + 首次 update 挂监听（`document` 或 `InputTarget`）+ 每帧末清理瞬时态；
- 三态轮询：`pressed`（持续）/ `justPressed`（单击）/ `justReleased`（松开那一帧）；
- `KeyboardInput`（`KeyCode` 字面量）、`MouseInput`（`MouseButton`）、`MouseWheel`、`MousePosition` 均为资源，系统用 `Res(...)` 读取；
- 修饰键自动合成；`InputTarget(canvas, true)` 可限域并 `preventDefault`；
- `app.destroy()` 释放 DOM 监听器。
